I'm inside the iframe

This document opts in to responsive sizing with a <meta name="responsive-embedded-sizing"> tag. The browser measures it on load. After that, it only resizes if the document calls window.requestResize().

What is this?

The embedding page sets frame-sizing: content-height on the iframe, so the browser sizes the iframe to the height of this document, with no scrollbars or postMessage code.
