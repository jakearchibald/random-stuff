Scoped registries: parser attributes

This page tests two parser-level opt-outs that leave a subtree with a null custom element registry, so a scoped registry can be attached later using registry.initialize(node):

  • <template shadowrootmode shadowrootcustomelementregistry> gives the declarative shadow root a null registry.
  • scopedcustomelementregistry is a global attribute (whatwg/html#12000) that gives the element, and the descendants the parser creates inside it, a null registry.
