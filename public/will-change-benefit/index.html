Does will-change actually help?

The car below is an inline SVG that's very expensive to paint — a few hundred paths with gradients — but nothing about it changes as it rotates. Try each method and watch how smoothly it turns.

Judge this by eye, and by the Performance panel in devtools. A frame-rate counter measured on the main thread would be misleading here: when the animation runs on the compositor, the main thread can be idle while the animation is perfectly smooth, and it can also be busy while the animation is still smooth.
