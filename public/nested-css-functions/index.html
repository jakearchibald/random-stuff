Nested CSS substitution functions

The name argument of var() and attr() can itself be the result of a var() or attr(). The styles for each demo are shown below it, and are editable.

Checking support…

var(var(…))

The inner var() returns a custom property name, which the outer var() then looks up.

Accent

var(var(var(…))) with a fallback

Chains work too. If any link resolves to something that isn't a custom property name, the fallback is used.

var(var(var(--start)))
var(var(var(--start-broken)), grey)

attr(attr(…))

The element's data-show attribute says which other attribute to display. Note the type(<custom-ident>): without it, the inner attr() returns a string, which isn't a valid attribute name.
