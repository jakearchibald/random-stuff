Compression dictionary demo

The resource is three.js's Vector4.js. The dictionary is three.js's Vector3.js, which has a lot of code in common with it.

  1. Fetch resource. With no dictionary, the response should be regular brotli (br).
  2. Load dictionary. The response has a Use-As-Dictionary header, so the browser stores it.
  3. Fetch resource again. The browser should send an Available-Dictionary header, and the server responds with dcb (brotli using the dictionary).
